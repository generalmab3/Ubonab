# درسنامه و اسلاید دفاع

`index.html` هم ارائهٔ جلسه است و هم درسنامهٔ کامل مخزن. فرمول‌ها با KaTeX و راست‌به‌چپ‌اند.

## اجرا

از ریشهٔ مخزن:

```bash
python3 -m http.server 8787 --bind 0.0.0.0
```

سپس `slides/index.html` را باز کنید.

## کلیدها

| کلید | کار |
|---|---|
| فاصله / چپ / پایین | اسلاید بعد (در RTL) |
| راست / بالا / Backspace | اسلاید قبل |
| N | یادداشت گوینده |
| F | تمام‌صفحه |
| Home / End | اول / آخر |
| ? | راهنما |
| P | چاپ همهٔ اسلایدها با یادداشت |

در صفحه، نوار راست اسلاید بعد است و نوار چپ اسلاید قبل.

## مسیر دفاع و مسیر مطالعه

- **دفاع (حدود ۲۵ تا ۳۵ دقیقه):** از عنوان تا «پرسش‌ها». اسلایدهای «چگونه از این فایل استفاده کنید»، درخت مخزن و «پرسش داور ۱…۱۵» را رد کنید مگر بپرسند.
- **تمرین:** N را روشن کنید. کادر طلایی همان جواب کوتاه داور است.
- **مطالعه:** کل ۶۷ اسلاید، از جمله مثال عددی لایه سخت، فایل‌های `code/` و پانزده پرسش‌پاسخ.

PDF همین محتوا: [`defense-handbook.pdf`](defense-handbook.pdf).

بازسازی PDF (قلم DejaVu سیستم؛ بدون XeLaTeX):

```bash
.venv/bin/pip install fpdf2 arabic-reshaper python-bidi
.venv/bin/python slides/make_pdf.py
```

اعداد اسلاید باید با `code/data/metrics.json` یکی باشند. استاد راهنما فقط دکتر بابک آذرنوید است.
