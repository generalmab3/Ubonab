# داده مطالعه موردی

`prepare_public_data.py` دو منبع عمومی را به یک سری ساعتی تبدیل می‌کند:

1. بار: مجموعه پیش‌بینی مصرف وسایل UCI (Candanedo 2017، DOI `10.24432/C5VC8G`). انرژی ده‌دقیقه‌ای وسایل و روشنایی به کیلووات تبدیل و در ساعت‌های کامل میانگین گرفته می‌شود؛ سپس بار زمینه `0.20 kW` افزوده می‌شود.
2. تابش: `ALLSKY_SFC_SW_DWN` روزانه NASA POWER برای Stambruges، بلژیک. کل روزانه با پوش ارتفاع خورشید روی ساعت‌های همان روز پخش می‌شود. توان فتوولتائیک نامی `1 kW` و نسبت عملکرد `0.82` است.

خروجی‌ها:

- `public_microgrid_case.csv` — سری ساعتی بار، فتوولتائیک و تعرفه
- `metadata.json` — منشأ، تبدیل‌ها و مختصات
- `metrics.json` — پس از `simulate.py`

بازه هدف: ۱۱ ژانویه ۲۰۱۶ ساعت ۱۷ تا ۲۷ مه ۲۰۱۶ ساعت ۱۷، به وقت `Europe/Brussels`، ۳۲۸۹ ساعت کامل.
